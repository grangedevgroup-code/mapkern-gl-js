Maps for the web, without the baggage.

Maplet GL JS draws vector tiles, raster tiles and GeoJSON with WebGL2. It has no dependencies, it's about 77 KB gzipped, and it can build its own street map tiles from OpenStreetMap data.

Get started See examples

A map in a few lines

Install it from GitHub:

npm install github:grangedevgroup-code/maplet-gl-js

Then give it a container and some data. This one needs no tile server or API key:

import * as maplet from "maplet-gl";

const map = new maplet.Map({
  container: "map",
  center: [-122.335, 47.608],
  zoom: 13,
  style: {
    version: 1,
    sources: { places: { type: "geojson", data: "places.geojson" } },
    layers: [
      { id: "background", type: "background", paint: { color: "#eef1ef" } },
      { id: "places", type: "circle", source: "places", paint: { radius: 7, color: "#246a50" } },
    ],
  },
});

Your own basemap

Download an OpenStreetMap extract, run npx maplet-tiles on the area you want, and you get a single file you can host anywhere. The map above comes from one of those files.

Live data

Replace GeoJSON while the map runs and the old data stays up until the new tiles are ready, so moving things never flicker.

No empty squares

While you pan and zoom, Maplet fills gaps with tiles it already has from other zoom levels and loads what's on screen first.
